# Sistema Club de Videos - Documentación General

Proyecto Universitario de **Bases de Datos Avanzadas**.

## Estructura Modular

- `containers/`: Infraestructura HA con HAProxy, OpenSearch Multi-nodo y Docker.
- `database/`: Mappings NoSQL, Scripts Painless y semillas.
- `backend/`: API REST en FastAPI con Clean Architecture, SOLID, OCC y Unit of Work.
- `frontend/`: Aplicación Flutter con arquitectura Feature-First y BLoC.
- `docs/`: Guías técnicas, bitácoras y preparación para videos de evaluación.
